# Changelog

## 1.0.0-rc1 (2026-04-06)

- Initial release candidate for ESP32-S3 GPS Lap Timer v1.0
- GPS lap timing with Catmull-Rom spline crossing detection at 25 Hz
- VBO file recording with power-loss recovery
- Real-time delta display (green/red) against best lap
- Sector split timing (up to 3 sector lines)
- WiFi AP with phone-based web dashboard
- Track management: create, select, delete, auto-detect by GPS
- Settings: WiFi SSID/password, display brightness
- TFT display: driving screen, status screen, lap list screen
- SD card session storage with JSON metadata sidecar
- Button controls: record toggle, screen cycle
