## TFT 屏接线

**模块型号：** ZJY320S0800TG02，3.2 寸，驱动 IC：ILI9341，8 根连线

| # | 模块引脚标注 | 连接位置 | 说明 |
|---|-------------|----------|------|
| 1 | GND | ESP32-S3 GND | 接地 |
| 2 | VCC | ESP32-S3 3.3V | **必须接 3.3V**，ILI9341 不支持 5V 逻辑/供电 |
| 3 | CLK | GPIO12 | SPI 时钟线 |
| 4 | MOS | GPIO11 | SPI MOSI（主机发送，屏幕接收） |
| 5 | RES | GPIO8 | 复位引脚，低电平复位 |
| 6 | DC | GPIO9 | 数据/命令选择：高电平=数据，低电平=命令 |
| 7 | CS | GPIO10 | 片选，低电平有效 |
| 8 | BLK | GPIO47 | 背光使能。接 GPIO 可用 PWM 控制亮度；若不需调光也可直接接 3.3V 常亮 |

**要点：**
- ILI9341 逻辑电平为 3.3V，若 VCC 误接 5V 会损坏芯片
- BLK 接 GPIO47 后，代码中用 `ledcWrite()` 即可实现亮度调节
- TFT 仅作为输出设备，无需 MISO 线

## SD 卡模块接线

**接口：** SPI，6 根连线

> 当前项目实物使用的是蓝色 SPI MicroSD 模块，板上可见 `1117-3.3`
> 稳压器和 `SN74HC125` 缓冲/电平处理芯片。对这块模块，`VCC`
> 建议接 **5V_SW**，不要从 ESP32 的 `3.3V` 脚给它供电。

| # | 模块引脚标注 | 连接位置 | 说明 |
|---|-------------|----------|------|
| 1 | GND | ESP32-S3 GND | 接地 |
| 2 | VCC | **5V_SW** | 当前这块带 `1117-3.3` 的模块建议接 **5V_SW** |
| 3 | MISO | GPIO13 | SD 卡数据输出，此引脚 TFT 不使用 |
| 4 | MOSI | GPIO11 | **与 TFT 共用**，同一根物理线 |
| 5 | SCK | GPIO12 | **与 TFT 共用**，同一根物理线 |
| 6 | CS | GPIO42 | SD 专用片选，与 TFT CS（GPIO10）独立 |

**共享 SPI 总线说明：**
- TFT 和 SD 卡共用 MOSI（GPIO11）和 SCK（GPIO12）
- 通过各自的 CS 引脚区分：操作 TFT 时拉低 GPIO10，操作 SD 时拉低 GPIO42
- 同一时刻只能有一个 CS 为低电平，不可同时操作两个设备
- Arduino/ESP-IDF 的 SPI 库会自动管理 CS，配置正确即可
- 若你换成纯 `3.3V` SPI 卡座，再把该模块 `VCC` 改接 `3.3V`

## GPS 模块接线

**模块型号：** Beitian BK-880 GNSS 模块，UART 通信，内置 QMC5883 电子罗盘

> 参考文档：《BK-880 GNSS 模块使用说明书》P2.0 (2025-07-06)
>
> BK-880 提供**两种电气接口**，信号定义相同：
>   1. **1.25mm 6P 卧式贴片座**（随模块自带线束）
>   2. **板上 2.54mm 通孔焊盘**（已实测间距为 2.54mm，可焊标准直插排针）
>
> 本项目洞洞板/PCB 版本使用 **2.54mm 通孔路径**：在模块板上焊 1×6 排针，
> 洞洞板/PCB 上装对应排母座即可插拔。避免处理 1.25mm 线束的压接工艺。
>
> UART TX/RX 为 **3.3V TTL** 电平，可直接接 ESP32-S3。
> **PPS 信号未引出到 6P 连接器**，仅板上 LED 和独立测试焊盘可用。

| # | 模块引脚标注 | I/O | 连接位置 | 说明 |
|---|-------------|-----|----------|------|
| 1 | SDA | O | 未接（预留） | I2C 数据，QMC5883 罗盘（未来可接 ESP32 I2C） |
| 2 | GND | G | ESP32-S3 GND | 接地；必须和 ESP32 共地 |
| 3 | TX | O | GPIO17 | GPS 模块发送 → ESP32 接收（**交叉连接**） |
| 4 | RX | I | GPIO18 | GPS 模块接收 ← ESP32 发送（**交叉连接**） |
| 5 | VCC | I | **5V_SW** | 主电源，DC 3.6-5.5V，推荐 5.0V |
| 6 | SCL | I | 未接（预留） | I2C 时钟，QMC5883 罗盘（未来可接 ESP32 I2C） |

**要点：**
- TX/RX 必须交叉：GPS 的 TX 接 ESP32 的 RX，GPS 的 RX 接 ESP32 的 TX
- 当前代码引脚定义见 [pins.h](/Users/wenchaodu/Documents/Claude_code_projects/ESP32_track_GPS/src/pins.h)：`RX=GPIO17`、`TX=GPIO18`、`PPS=GPIO16`
- **PPS (GPIO16) 当前无法通过线束连接**；如需 PPS，须在模块 PCB 的 PPS 测试焊盘上飞线
- 当前固件会自动尝试 `115200 / 38400 / 9600` 三种常见波特率；探测到后会尽量切到 `115200`
- 25Hz 下 NMEA 数据量较大，长期稳定运行仍建议最终工作在 `115200`
- SDA/SCL 为 QMC5883 电子罗盘 I2C 接口，当前项目未使用，线束上预留即可
- 若 GPS 模块单独接 5V 供电，**一定要和 ESP32 共地**

## 按钮接线

### 按钮 1：自锁总开关（推荐接法）

自锁按钮不再接到 `GPIO4`，而是直接串在系统 `5V` 正极上，作为整机
总开关使用：

```text
取电板 5V ──────── 自锁按钮 ──────── 5V_SW
取电板 GND ──────────────────────── 公共地
```

| 按钮 | 类型 | 连接方式 | 功能 |
|------|------|----------|------|
| 按钮 1 | 12mm **锁定**（自锁）按钮 | 串联在 `5V` 正极 | 系统总开关 |

**要点：**
- 只切 `5V` 正极，**不要切 GND**
- 自锁按钮放在 `5V` 分电点之前，按钮后的电源母线统一记作 `5V_SW`
- `5V_SW` 同时供给 ESP32 `5V/VIN`、GPS `VCC`、SD 模块 `VCC`

### 按钮 2：录制键（GPIO 输入）

```text
GPIO4 ──────── 按钮一端
                  |
               [按钮]
                  |
GND  ──────── 按钮另一端
```

| 按钮 | 类型 | GPIO | 功能 |
|------|------|------|------|
| 按钮 2 | 12mm **瞬动**（自复位）按钮 | GPIO4 | 录制开始 / 停止 |

**代码初始化示例：**
```cpp
pinMode(4, INPUT_PULLUP);  // 按钮2，按下时读到 LOW
```

### GPIO5 扩展键（当前未装配）

当前硬件版本没有把第二颗 GPIO 按键装到 `GPIO5`。固件保留了
`PIN_BTN_SECTOR` 这个扩展位，但在当前设备上它不是必接项。

**要点：**
- 当前量产/原型接线只需要 `GPIO4` 录制键即可
- 若以后增加页面切换或手动扇区功能，可把一颗额外的自复位按钮接到 `GPIO5`
- GPIO 输入按钮启用 `INPUT_PULLUP` 后无需外接上拉电阻

## 电源接线

**推荐方案：5V USB-C 电池 → 取电板 → 自锁开关 → `5V_SW` 主电源母线**

```text
5V USB-C 电池
      |
      | USB-C 线
      |
USB-C 取电板 / 分电板
      |
      +---- GND ------------------------------------------+
      |                                                   |
      +---- 5V ---- 自锁按钮 ---- 5V_SW ------------------+----> ESP32 5V / VIN
                                                          +----> GPS VCC
                                                          +----> SD VCC

ESP32 3.3V ----------------------------------------------------> TFT VCC
```

- `5V_SW` 是自锁按钮后的系统主电源母线
- `ESP32` 建议从 `5V/VIN` 供电，不再把电池长期直接插在开发板 USB 口上
- `GPS BK-880` 建议从 `5V_SW` 供电；已确认当前模块 `TX/RX` 是 `3.3V TTL`
- 当前这块带 `1117-3.3` 的 `SD` 模块建议从 `5V_SW` 供电
- `TFT` 继续使用 ESP32 板上的 `3.3V` 引脚供电
- **所有 GND 必须共地**

**烧录模式（推荐操作流程）：**

1. 自锁总开关拨到 `OFF`
2. 电脑 USB 接到 ESP32 开发板
3. 烧录固件
4. 烧录完成后拔掉电脑 USB
5. 自锁总开关拨到 `ON`，恢复电池供电

> 说明：Espressif 官方把 `USB` 供电与 `5V/GND` 针脚供电列为互斥的上电方式。
> 为避免双路 `5V` 互相回灌，烧录时不要让外部 `5V_SW` 同时喂进 ESP32。

**3.3V 引脚电流预算（参考）：**

| 模块 | 典型电流 |
|------|---------|
| TFT ILI9341 | ~20 mA |
| LED | ~5-10 mA |
| **合计** | ~25-30 mA |

ESP32-S3 板载 LDO 给 TFT 和少量逻辑负载供电是安全的；GPS 和当前 SD 模块
都不再占用板载 `3.3V` 预算。

## 注意事项

### 1. 避开的 Strapping 引脚

ESP32-S3 启动时以下引脚电平会影响启动模式，**慎用或避用**：

| 引脚 | 说明 |
|------|------|
| GPIO0 | 启动模式选择（低电平=下载模式），避免接外部上拉/下拉 |
| GPIO3 | JTAG 相关，启动时需为低电平，谨慎使用 |
| GPIO45 | VDD_SPI 电压选择（影响 Flash），不可随意拉高/拉低 |
| GPIO47 | 已用作 TFT BLK；注意该引脚在某些版本中也是 strapping pin，启动完成后可正常使用 |

**GPIO47 特别说明：** 在 ESP32-S3 中，GPIO47 是 strapping pin（控制 ROM 消息打印），默认需为低电平。BLK 背光默认低电平（关背光）不影响启动，上电稳定后再用 PWM 控制，实测无问题。若遇到启动异常，可改接其他非 strapping 引脚。

### 2. 3.3V vs 5V 注意事项

| 模块 | 供电电压 | 说明 |
|------|---------|------|
| TFT ILI9341 | **3.3V** | 不可接 5V，会损坏驱动 IC |
| GPS BK-880 | **5V_SW** | 当前项目实测这块载板更适合 5V 输入；UART 仍是 3.3V TTL |
| SD 卡模块 | **5V_SW** | 当前实物这块蓝色模块带 `1117-3.3`，建议接 5V_SW |
| 按钮 | 视接法而定 | 自锁总开关串在 5V 正极；GPIO 按钮只需 GPIO + GND |

### 3. 共享 SPI 总线注意事项

- MOSI（GPIO11）和 SCLK（GPIO12）由 TFT 和 SD 卡共享，使用同一根导线分别接到两个模块
- 同一时刻只能激活一个 CS：操作 TFT 时 GPIO10=LOW、GPIO42=HIGH；操作 SD 时 GPIO42=LOW、GPIO10=HIGH
- Arduino 的 `TFT_eSPI` 库和 `SD` 库均支持共享 SPI 总线，配置文件中指定各自 CS 引脚即可
- SPI 频率：TFT 可达 40-80 MHz；SD 卡建议 25 MHz 以下

### 4. GPS 串口接线验证

- 上电后若 GPS 无 NMEA 输出，首先检查 TX/RX 是否接反
- 当前实测这块 BK-880 在 5V 模块供电下，TX 仍输出约 3.0-3.3V TTL 电平，可直接接 ESP32-S3
- PPS 灯闪烁不等于线束一定已经把 1PPS 引脚导出；接线前先确认模块焊盘或附带线束定义
- 默认等待 30-60 秒冷启动定位；首次上电或室内环境可能更久

### 5. 走线建议

- SPI 线尽量短，避免长线干扰（特别是高速 TFT 刷新时）
- GPS 模块远离 ESP32 核心，减少 RF 干扰
- 电源线尽量粗短；在 GPS `VCC/GND` 附近建议放 `10μF + 100nF`
- 在 SD 模块 `VCC/GND` 附近建议放 `100μF~220μF + 100nF`
- 在 TFT `3.3V/GND` 附近建议放 `10μF + 100nF`

### 6. 烧录与双供电注意事项

- 运行模式：自锁总开关 `ON`，电池经 `5V_SW` 给 ESP32、GPS、SD 供电
- 烧录模式：自锁总开关 `OFF`，只接电脑 USB 给 ESP32 供电和烧录
- 不建议在外部 `5V_SW` 仍连接 ESP32 `5V/VIN` 时，再把电脑 USB 同时插上
- 若设备正在录制，关机前先停止录制，再断开总电源，可减少 `_recording.vbo.tmp` 恢复压力

## GPIO 引脚汇总

| GPIO | 功能 | 说明 |
|------|------|------|
| GPIO2 | LED | 状态指示灯 |
| GPIO4 | REC 输入 | 独立自复位录制按钮 |
| GPIO5 | 预留扩展位 | 当前硬件未装配 |
| GPIO8 | TFT RST | 屏幕复位 |
| GPIO9 | TFT DC | 数据/命令选择 |
| GPIO10 | TFT CS | TFT 片选 |
| GPIO11 | SPI MOSI | TFT + SD 共享 |
| GPIO12 | SPI SCLK | TFT + SD 共享 |
| GPIO13 | SPI MISO | SD 卡专用 |
| GPIO16 | PPS 预留位 | 秒脉冲（可选；当前 1×6 线束不引出，如需使用需飞线到测试焊盘） |
| GPIO17 | UART1 RX | 接 GPS TX |
| GPIO18 | UART1 TX | 接 GPS RX |
| GPIO42 | SD CS | SD 卡片选 |
| GPIO47 | TFT BLK | 背光 PWM 控制 |

> 自锁总开关不占用 GPIO；它是串在 `5V` 正极上的物理电源开关。
