# Kart GPS Lap Timer — 产品需求文档 (PRD)

**版本**: v0.2
**更新日期**: 2026-04-02

## 1. 项目概述

为卡丁车赛道设计的便携式 GPS 圈速计时器，安装在方向盘上，实时显示与最佳圈的时间差值（Delta），帮助车手在驾驶过程中精确定位每个弯角的快慢，并记录完整轨迹数据供赛后分析。

## 2. 目标用户

- 租赁卡丁车爱好者
- 会去不同赛道
- 需要在驾驶中实时获取圈速反馈
- 需要赛后导出数据用专业软件分析

## 3. 硬件配置

| 组件 | 型号 | 规格 |

| 主控 | 鹿小班 ESP32-S3-N16R8 | 双核 240MHz, 16MB Flash, 8MB PSRAM, WiFi+BLE |

## 4. 功能需求

### 4.1 核心功能：Position-Based 实时 Delta 计时

**优先级：P0（必须）**

- **基于 GPS 位置的 Delta 计算**（Position-Based Delta）：每次 GPS 更新时，根据当前 GPS 坐标在赛道上的位置，查找最佳圈经过同一位置的时间，计算差值。不使用距离或时间进度，避免因走线差异导致 Delta 漂移
- Delta 精度：±50ms 以内
- 基于 GPS 坐标的过线检测（样条插值算法）
- 支持自由设置扇区数量（每条赛道可独立配置）
- 实时显示已跑过的各扇区 Delta
- 颜色编码：绿色 = 快于最佳圈，红色 = 慢于最佳圈

### 4.2 最佳圈定义

**优先级：P0（必须）**

- 支持两种模式，可通过手机 Web 界面切换：
  - **本次 Session 最佳圈**：每次开机重新计算
  - **历史最佳圈**：跨 Session 保留，存储在 SD 卡中

### 4.3 赛道管理

**优先级：P0（必须）**

- 预存赛道库，保存在 SD 卡中
- 每条赛道包含：
  - 赛道名称
  - 起终线坐标（两点经纬度，连线作为检测线）
  - 扇区分割线坐标（每条分割线也是两点经纬度连线）
  - 扇区数量（自由设置）
  - 历史最佳圈数据
  - 赛道中心坐标（用于自动识别）

### 4.4 赛道自动识别

**优先级：P0（必须）**

- 开机 GPS 定位后，自动匹配赛道库中距离最近的赛道（搜索半径 50km）
- 屏幕显示"已识别：XX赛道"
- 如果识别错误，可通过手机 Web 界面切换

### 4.5 赛道创建

**优先级：P1（重要）**

支持三种方式创建赛道：

1. **现场校准圈**：开一圈校准圈，在手机 Web 界面上按按钮标记起终点和扇区分割点
2. **地图点选**：在手机 Web 界面的卫星地图上，手指点选起终线和扇区位置
3. **手动输入经纬度**：在手机 Web 界面中直接输入起终线两端的经纬度坐标

### 4.6 无效圈自动过滤

**优先级：P0（必须）**

- 圈速超过最佳圈 150% 的圈自动标记为无效圈
- 无效圈不计入最佳圈统计，不影响 Delta 参考基准
- 适用场景：进站圈、暖胎圈、慢速圈、红旗中断
- 在 Web 界面中可手动标记/取消标记无效圈

### 4.7 Session 自动开始/停止

**优先级：P1（重要）**

- **自动开始**：GPS 检测到速度 > 15km/h 时自动开始记录
- **自动停止**：静止超过 5 分钟自动结束当前 Session
- 无需手动操作，上车跑就自动记录

### 4.8 数据记录

**优先级：P0（必须）**

- 自动保存到 SD 卡，无需手动操作
- 文件格式：VBO（Racelogic VBOX 格式）
- 文件命名：`日期_赛道名_时间_session编号.vbo`
  - 示例：`20260402_ShanghaiKartCenter_143022_001.vbo`
- 记录频率：与 GPS 刷新率一致（10-25Hz）
- 兼容 Circuit Tools、VBOX Tools 等分析软件

### 4.9 VBO 文件格式要求

文件结构：

```
File created on DD/MM/YYYY at HH:MM:SS

[header]
satellites
time
latitude
longitude
velocity kmh
heading
height

[comments]
Generated by Kart GPS Lap Timer v1.0
Log Rate (Hz) : 25.00

[session data]
name 赛道名称

[laptiming]
Start  lat1 lon1 lat2 lon2 Start / Finish
Split  lat1 lon1 lat2 lon2 Split 1
Split  lat1 lon1 lat2 lon2 Split 2

[column names]
sats time lat long velocity heading height

[data]
(空格分隔的数据行)
```

GPS 坐标格式：角分制（十进制度 × 60），北纬为正，西经为正
行结尾：Windows CR+LF

### 4.10 手机交互（WiFi + Web 界面）

**优先级：P0（必须）**

- ESP32 自建 WiFi 热点，手机连接后浏览器访问配置页面
- iOS / Android 浏览器通用，无需安装 App
- Web 界面功能：
  - 选择赛道
  - 创建新赛道（三种方式）
  - 设置扇区分割点
  - 切换最佳圈定义（本次/历史）
  - 下载 VBO 文件
  - 查看历史圈速数据
  - 手动标记/取消无效圈

### 4.11 VBO 文件传输

**优先级：P1（重要）**

- **方式 A**：拔 SD 卡插电脑读取
- **方式 B**：WiFi 下载 — ESP32 开热点，手机/电脑连接后浏览器下载

## 6. 系统工作流程

```
[开机]
  │
  ▼
[GPS 定位中] ← 屏幕显示卫星搜索动画和卫星数量
  │
  ▼ (定位成功, 卫星数 ≥ 6, HDOP ≤ 2.0)
  │
[自动匹配赛道] ← 根据 GPS 坐标匹配赛道库中最近的赛道（50km 范围）
  │
  ├── 匹配成功 → 屏幕显示"已识别：XX赛道"
  │
  └── 匹配失败 → 屏幕显示"未知赛道，请用手机配置"
  │
  ▼
[等待起跑] ← 屏幕显示 Ready + 赛道信息
  │
  ▼ (速度 > 15km/h，自动开始记录)
  │
[自动开始 SD 卡记录]
  │
  ▼ (GPS 检测到越过起终线)
  │
[自动开始计时]
  │
  ├── 每次 GPS 更新 → 计算 Position-Based Delta
  │
  ├── 每越过扇区线 → 记录扇区时间，更新扇区 Delta
  │
  ├── 每越过起终线 → 完成一圈
  │   ├── 圈速 > 最佳圈 × 150% → 标记为无效圈
  │   └── 有效圈 → 更新最佳圈和 Delta 参考基准
  │
  └── 实时写入 VBO 数据到 SD 卡
  │
  ▼ (静止 > 5 分钟，自动结束 Session)
  │
[保存 Session 数据, 关闭 VBO 文件]
  │
  ▼ (用户关机)
  │
[断电]
```

## 9. 技术约束

- GPS 坐标系：WGS84
- VBO 坐标格式：角分制（十进制度 × 60）
- SPI 时钟：屏幕和 SD 卡共用 SPI 总线，独立 CS 线
- 内存：PSRAM 8MB 用于屏幕帧缓冲，内部 SRAM 用于 GPS 数据处理
- Position-Based Delta 需要存储最佳圈的完整 GPS 轨迹数据（约 50-100KB/圈）
- 电池续航目标：≥ 10 小时（4000mAh, 系统功耗约 300mA）
- 工作温度：-20°C ~ 70°C（屏幕规格书标称）
