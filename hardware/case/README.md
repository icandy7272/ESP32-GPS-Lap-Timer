# 外壳设计与打印（hardware/case）

3D 打印外壳的参数化模型 + 工作流。**所有尺寸在 `case.scad` §1 顶部当变量**——量完
直接填，重新预览，导 STL 下单打印。

## 工作流

### 第 1 步：测量（30 分钟）

游标卡尺 + 一杯茶。把 `case.scad` 的 §1 全部填一遍。**每项量 3 次取最大值**——FDM
打印的容差更喜欢宽松不要紧，紧了装不进去。

具体测哪些 → 直接看 `case.scad` 顶部的清单，注释里都讲清楚每项怎么量。

### 第 2 步：预览（5 分钟）

```bash
brew install openscad      # 一次性装好（macOS）
open -a OpenSCAD hardware/case/case.scad
```

OpenSCAD 里按 **F5** 实时预览（毛糙但快）。

改一个数字，按 F5，立刻看效果。这是参数化设计的爽点——比 Fusion 360 的 GUI 快多了。

### 第 3 步：渲染 + 导出（2 分钟）

按 **F6** 高质量渲染（慢，要等几秒到几十秒）。然后 **File → Export → Export as STL**。
你会得到 `case.stl`。

模型里的 `bottom_case()` 和 `top_lid()` 是分开的两个件——预览时上盖飘在上面方便检查
设计，**导出时它们会作为同一个 STL 的两个 mesh 出现**。打印软件里两件分别摆好打。

> 如果想分别导出底壳 / 上盖，把 §6 PREVIEW 段里其中一行注释掉，导一遍，再注释另一行。

### 第 4 步：下单或自打（3-5 天 / 一晚）

**外协（推荐前 3 版）：**
- **嘉立创 3D 打印**（jlc3dp.com）— 最便宜，PLA 单件 ~30 元、PETG ~50 元
- **打印宝**、淘宝小作坊 — 看店家口碑，但便宜

**首版材料**：**PLA**（便宜、易打、出问题不心疼）。30% 填充、0.2mm 层高、不开支撑（如果模型设计合理，FDM 桥接 ≤6mm 跨度可以无支撑）。

**稳定后**：**PETG**（耐热 75-90°C，抗冲击好，符合 [PRD §设备物理结构](../../docs/PRD.md)）。30% 填充、0.2mm 层高、加 brim 防翘边。

### 第 5 步：试装 → 记录 → 迭代

打印件到手后**先空腔试装**（板子不上电，纯机械配合）：

- TFT 螺丝孔对得上吗？
- ESP32 的 USB-C / BOOT / RST 都摸得到吗？
- 18650 电池仓塞得进吗？
- M12 按键能从外侧穿过去并锁紧吗？
- 合盖时有没有线被夹？

**每个问题记到 `case.scad` 文件底部的 §7 FIT NOTES**——下次改的时候不用记忆。

第 1 版基本会有 3-5 个问题，正常。改完 v1 → v2 重打，一般 3-4 版稳定。

### 第 6 步：稳定后做最终件

- PETG 重打一次
- 装上车开几圈，做振动测试（参考 [TODOS.md Stage A 后续验证](../../TODOS.md)）
- 如果你的卡丁车户外环境湿 / 灰，外壳合缝可以加一道硅胶 O 圈密封

## 软件要求

| 工具 | 用途 | 免费? |
|------|------|------|
| **OpenSCAD** | 编辑 / 预览 / 导出 STL | ✅ |
| 切片软件（Slicer） | STL → G-code（自打才需要） | ✅（PrusaSlicer / Bambu Studio / Cura 任一） |

如果你外协打印（嘉立创 / 打印宝），你只需要 OpenSCAD。

## 为什么走 OpenSCAD 不走 Fusion 360

这个项目其他东西全在 git 里，外壳模型也走 `git diff` 才一致。OpenSCAD 是纯文本，每次
改一个尺寸就是一个干净的 commit，团队协作也好 review。Fusion 360 是二进制 cloud 文件，
不进 git。代码风格的人会更喜欢 SCAD。

如果你想用 Fusion 360：导出 STL 后扔到这里也行，但对照 `case.scad` 里的尺寸来建模，
别让两个文件分叉。

## 常见坑

| 坑 | 解决 |
|------|------|
| 螺丝孔太紧 / 螺丝拧裂 PLA | 孔径加 +0.3mm，配自攻螺丝（M2 自攻孔孔径 1.7mm） |
| TFT 窗口边沿粗糙 | 窗口边再加一圈 0.5mm 倒角，视觉掩盖层纹 |
| 卡扣易断 | 用 M2 螺丝替代卡扣（已在模型里这么做了） |
| 平面翘边 | PLA 床温 50-60°C，PETG 床温 75-85°C，加 brim |
| 桥接面下垂 | 跨度 ≤6mm 通常没事；超过加内部支撑或调整模型方向 |
| 0.5mm 以下细节糊 | 0.4mm 喷嘴极限是 0.5mm 壁厚，更细换 0.2mm 喷嘴 |
| GPS 信号变差 | 顶盖**绝对不要**贴金属铭牌、刷导电涂层、用碳纤维板 |
